## Local Preview

The site can be opened directly from `index.html`, or served locally:

```sh
python3 -m http.server 4173
```

Then visit:

```txt
http://127.0.0.1:4173/index.html
```

## Before Publishing

Confirm the GitHub and LinkedIn URLs in `index.html`:

- `https://github.com/nanangcahya`
- `https://www.linkedin.com/in/nanangcahya/`

The public contact section intentionally shows email, GitHub, and LinkedIn only. The phone number from the CV is not displayed to reduce spam risk.
