Case study - PT Telkom Indonesia

Online Single Submission system

Backend leadership for a national risk-based licensing workflow, focused on service architecture, API integration, deployment discipline, and review visibility for operational teams.

Project facts

Role
Technical Leader / Senior Web Engineer
Scale signal
National risk-based licensing workflow with multiple stakeholder groups
Stack
Node.js, NestJS, ExpressJS, GitLab CI/CD
Domain
Risk-based licensing and operational submission workflows

Context

The product needed to support Indonesia's risk-based licensing workflow, where submission intake, review visibility, stakeholder coordination, and system integration were more complex than a simple form-based application.

Constraints

The system required coordination across multiple stakeholder groups, clear documentation, reviewable API behavior, role-aware workflow handling, and deployment discipline suitable for production operational workflows.

Architecture

I helped shape a service-oriented backend using ExpressJS and NestJS, separating concerns around submission workflows, review flows, integrations, and delivery automation. GitLab CI/CD, code reviews, and technical documentation were part of the production delivery model.

Tradeoffs

The architecture favored explicit service boundaries and reviewable API contracts over a single tightly coupled application. That made delivery coordination more deliberate, but improved maintainability, ownership, and release confidence for a workflow with changing operational rules.

Impact

The work supported a national-scale operational workflow, standardized submission and review visibility, reduced reliance on manual tracking, and gave the team a clearer release process for ongoing delivery.

What this demonstrates

Senior-level ownership across requirements translation, service design, backend implementation, documentation, reviews, and delivery coordination.
