Case study - PT Phincon

MyTelkomsel mobile app APIs

Backend API development and migration support for a national telecom mobile product, focused on reliability, performance, CI/CD consistency, and maintainability.

Project facts

Role
Senior Web Developer / Lead Web Developer
Scale signal
Production telecom mobile services for a national product team
Stack
HapiJS, ExpressJS, Golang, Redis, MySQL, CI/CD
Domain
Telecom mobile app backend APIs

Context

MyTelkomsel mobile services needed reliable REST APIs and a path away from monolithic service constraints toward backend capabilities that were easier for mobile product teams to maintain and evolve.

Constraints

API work had to support production telecom workflows while improving performance, deployment consistency, and maintainability across mobile service teams without disrupting active product delivery.

Architecture

I developed REST APIs using HapiJS, ExpressJS, and Golang, with Redis and MySQL supporting performance-sensitive service behavior. CI/CD pipeline work improved repeatability, while code structure and system design mentoring helped the team keep services maintainable.

Tradeoffs

The migration approach balanced product continuity with architectural improvement. Rather than rewriting everything at once, the team moved capabilities toward service-oriented APIs while preserving production behavior for mobile-app workflows.

Impact

The work increased reliability of mobile service delivery by maintaining production APIs, reducing delivery friction through consistent deployment practices, and helping telecom mobile service teams evolve backend systems toward a more scalable architecture.

What this demonstrates

Practical senior engineering judgment across API delivery, performance work, migration support, CI/CD, and team mentorship.
